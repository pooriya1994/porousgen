PorousGen — parameter builder

Pick an architecture, tune it, watch the geometry update live. Every run writes .dat + .stl + .png + _info.txt.

Command line

Python

Install once with pip install . inside the package folder (Windows x64 / Linux / macOS — see WINDOWS_BUILD.md for a standalone .exe). Porosity is honoured exactly for cellular, foam, gyroid, blob and overlapping-sphere architectures (and for fibrous / fractured when a porosity is passed in Python). The command is lower-case porousgen; python -m porousgen.cli is equivalent.
